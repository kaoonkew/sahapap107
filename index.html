06 / AI USAGE

การใช้ AI ในการพัฒนา

ใช้กระบวนการ Think → Prompt → Result → Refine และตรวจสอบโค้ดก่อนนำไปใช้จริง

Think

กำหนดโจทย์

สรุปข้อมูลที่เว็บไซต์ต้องมี และวางโครงสร้างให้ครอบคลุมข้อกำหนดของรายวิชา

Prompt

สื่อสารกับ AI

ระบุ Context, Intent และ Constraints เช่น ใช้ HTML/CSS/JavaScript และต้อง Responsive

Result

ตรวจสอบผลลัพธ์

เปิดหน้าเว็บ ตรวจไฟล์ CSS/JavaScript และทดสอบการแสดงผลแทนการเชื่อคำตอบของ AI ทันที

Refine

แก้ไขและทดสอบซ้ำ

เมื่อพบปัญหา CSS หรือเนื้อหาไม่แสดง จึงวิเคราะห์สาเหตุ ปรับโค้ด และสร้างชุดไฟล์ใหม่ที่ปลอดภัยกว่าเดิม

AI Disclosure

เว็บไซต์นี้ใช้ ChatGPT เป็นผู้ช่วยด้านการวางแผนโครงสร้าง ร่างโค้ด ตรวจสอบปัญหา และเสนอแนวทางปรับปรุง ผู้จัดทำเป็นผู้ตรวจสอบ แก้ไข และรับผิดชอบผลงานขั้นสุดท้าย
